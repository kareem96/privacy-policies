# Privacy Policies

Kebijakan privasi untuk aplikasi-aplikasi yang dipublikasikan oleh Kareem Dev. Satu repo, satu folder per app di `docs/`, di-serve lewat GitHub Pages.

## Tambah app baru
1. Bikin folder baru `docs/<nama-app>/`
2. Taruh `index.md` isi kebijakan privasi app itu
3. URL otomatis jadi `https://kareem96.github.io/privacy-policies/<nama-app>/`
